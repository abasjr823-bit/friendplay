# FriendPlay - Multiplayer Gaming Platform

A production-ready multiplayer browser gaming platform combining Spyfall and Skribbl.io style games.

## Features

- 🎮 **Two Games**: Spyfall & Draw & Guess
- 🔄 **Real-time Multiplayer**: Powered by Socket.IO
- 🎯 **Room System**: Create, join, and manage rooms
- 📊 **Leaderboards**: Track player stats
- 🌍 **Multilingual**: English & Arabic with RTL support
- 🎨 **Modern UI**: Premium gaming aesthetic
- 📱 **Responsive**: Works on desktop and mobile

## Getting Started

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`
